# KITT Launcher.2

A Knight Rider (KITT) themed home-screen launcher for **7" to 10" landscape** Android car head
units (1024x600, 1280x720, 1280x800 and similar): OBD-II car scanner, an AI co-pilot that sees
your live vehicle data, map search with spoken directions, a browser for streaming and AI chat,
and the always-on red scanner light. A lighter Lite mode keeps it quick on budget head units.

It installs alongside the original [KITT Launcher](https://github.com/tdater/KITT-Launcher-releases), which is laid out
for big portrait screens. **[See everything it does, and which edition to pick](https://tdater.github.io/KITT-Launcher-releases/#editions)**.

## Download

**[Get the latest APK](https://github.com/tdater/KITT-Launcher.2-releases/releases/latest)** (under *Assets*).

## Install

1. Download the `.apk` on the head unit (or copy it over on a USB stick).
2. Open it and allow your browser or file manager to install unknown apps when Android asks.
3. Press Home and choose **KITT Launcher.2**, then **Always**, to make it the home screen.

Requires Android 7.0 or newer.

## Updates

KITT Config → Updates checks this page and installs newer versions for you.
